1. RealTraffic kya hai?

RealTraffic ek multi-feature traffic & lead automation platform hai jo 4 main kaam karta hai:

ModuleKya karta hai
CPI WorkerAndroid phones pe automatically apps install karke conversions generate karta hai
Real User Traffic (RUT)Real browser sessions chala kar surveys/forms automatically fill karta hai
Form FillerCustom form filling engine — koi bhi form, real user behavior simulation
Link TrackingBranded short links, click analytics, conversion postbacks

Tech Stack

  • 🐍 Backend: FastAPI + Python + Playwright + MongoDB
  • ⚛️ Frontend: React + Tailwind (Vercel pe deploy)
  • 🐳 Deploy: Docker Compose (Windows PC pe owner ka apna)
  • ☁️ Public access: Cloudflare Tunnel
⬆ Top

2. System Requirements

Owner ki Windows PC (production server)

  • Windows 10/11 (64-bit)
  • 8 GB RAM minimum (16 GB recommended)
  • 50 GB free disk space
  • Docker Desktop: Download
  • Git for Windows: Download
  • Stable internet for Cloudflare Tunnel
  • Cloudflare account (free) for tunnel setup

CPI Worker (Android phones)

  • USB-debugging enabled phones
  • USB hub (recommended for multiple phones)
  • ADB drivers installed

End-users ka kuch nahi chahiye

  • Bas browser (Chrome / Firefox / Edge)
  • App URL: https://realtraffic.online ya aapka custom domain

3. First-time Setup (One-time)

Step-by-step (~30 min):

  1. Repo clone karen: 
    cd F:\online
git clone https://github.com/lenovogen03/lenovo-realtraffic.git
cd lenovo-realtraffic
  2. .env file banayen backend/ folder mein: 
    JWT_SECRET_KEY=your-very-long-random-secret-min-32-chars
ADMIN_EMAIL=admin@realtraffic.local
ADMIN_PASSWORD=YourStrongAdminPassword123
POSTBACK_TOKEN=any-secret-token-for-postback-auth
APP_URL=https://realtraffic.online
PUBLIC_BASE_URL=https://api.realtraffic.online
TUNNEL_TOKEN=your-cloudflare-tunnel-token
  3. Cloudflare Tunnel setup:
    • one.dash.cloudflare.com → Networks → Tunnels → Create
    • Naam: realtraffic-tunnel
    • Token copy karen → .env ke TUNNEL_TOKEN mein paste
    • Domain: api.realtraffic.online → http://backend:8001
  4. Service Account JSON (Google Sheets ke liye) — Section 23
  5. Docker Desktop chalu karen
  6. FRESH-DEPLOY.bat chalayen
  7. Health check: https://api.realtraffic.online/health
  8. Admin login: https://realtraffic.online/admin — Section 7
  9. Email settings: Section 13
⬆ Top

4. Daily Update / Resync

Jab GitHub pe naye commits push hon, production wapas sync karne ke liye:

  1. Project folder mein jayen: cd F:\online\lenovo-realtraffic
  2. REALTRAFFIC-FORCE-SYNC.bat chalayen (double-click)
  3. Yeh khud kar lega: git fetch + reset + Docker rebuild + restart

53. Emergency Recovery

Sab kuch broke ho gaya

  1. Stop: REALTRAFFIC-STOP.bat
  2. Backup MongoDB volume: 
    docker run --rm -v realtraffic_mongo-data:/data -v F:\backups:/backup ubuntu tar czf /backup/mongo-emergency.tar.gz /data
  3. Fresh clone: 
    cd F:\online
git clone https://github.com/lenovogen03/lenovo-realtraffic.git realtraffic-fresh
cd realtraffic-fresh
  4. Configure .env + backend/secrets/gsheets-sa.json
  5. FRESH-DEPLOY.bat
  6. Restore Mongo (zarurat ho): 
    docker compose stop backend
docker run --rm -v realtraffic-fresh_mongo-data:/data -v F:\backups:/backup ubuntu tar xzf /backup/mongo-emergency.tar.gz -C /
docker compose start backend

Worst case: Mujhe (agent) batayen, mein step-by-step recover kar dunga.
